# Репозиторий для сдачи лабораторных работ по курсу «Программирование на Java»

Студент: ***Сосновских Татьяна***

Группа: ***25КНТ-5***

---
В данном репозитории содержатся выполненные практические и лабораторные работы по изучению языка программирования **Java**. Каждая работа находится в своей директории.

---
## Структура репозитория
```text
Java-coding/                      # Корень репозитория
├── 1st-task/                     # Папка первой лабораторной работы
│   ├── README.md                 # Файл с документацией
│   └── solution/                 # Директория с исходным кодом
│       ├── Main.java             # Консольный интерфейс, меню и обработка ошибок
│       ├── Matrix.java           # Логика двумерных массивов и матричной алгебры
│       └── Complex_number.java   # Логика хранения и вычисления комплексных чисел
│
├── 2nd-task/                     # Папка второй лабораторной работы
│   ├── README.md
│   └── solution/                         
│               
├── 3rd-task/                     # Папка третьей лабораторной работы
│   ├── README.md
│   └── solution/                        
├── ... 
│                            
└── Nth-task/                     # Папка N-ой лабораторной работы
    ├── README.md
    └── solution/  
```
---
