# Лабораторная работа №1: Калькулятор матриц комплексных чисел на Java

Программа позволяет инициализировать матрицы через консольный интерфейс и выполнять над ними базовые и сложные алгебраические операции.

---

## 📚 Математическая логика и формулы

### 1. Комплексные числа (`Complex_number.java`)
Каждое число представляется в виде *z = a + bi*, где *a* — вещественная часть (`real`), *b* — мнимая часть (`imaginary`).
*   **Сложение:** `(a + bi) + (c + di) = (a + c) + (b + d)i`
*   **Вычитание:** `(a + bi) - (c + di) = (a - c) + (b - d)i`
*   **Умножение:** `(a + bi) * (c + di) = (ac - bd) + (ad + bc)i`
*   **Деление:** Чтобы разделить на комплексное число, числитель и знаменатель умножаются на сопряженное число `(c - di)`:
    `(a + bi) / (c + di) = ((ac + bd) + (bc - ad)i) / (c² + d²)`


### 2. Матричные операции (`Matrix.java`)

*   **Транспонирование:** Строки и столбцы меняются местами. Новая матрица получает размеры (`cols, rows`) вместо исходных (`rows, cols`).
*   **Сложение и вычитание:** Выполняются поэлементно. Операции возможны строго для матриц одинакового размера.
*   **Умножение матриц:** Каждая ячейка результирующей матрицы рассчитывается как скалярное произведение строки матрицы *A* на столбец матрицы *B*. Операция возможна, только если количество столбцов *A* совпадает с количеством строк *B*.
*   **Определитель:** Вычисляется рекурсивным методом разложения по первой строке. Метод работает только для квадратных матриц.
*   **Деление матриц:** Операция *A / B* эквивалентна умножению матрицы *A* на матрицу, обратную *B*, т.е. *A * B⁻¹*. Обратная матрица находится через присоединенную матрицу миноров и детерминант. Операция возможна, если детерминант *B* не ноль.

## 💻 Технологии и особенности реализации

При написании проекта использовались ключевые концепции языка **Java**:
*   **Многоуровневая обработка исключений (try-catch):** Консольный интерфейс полностью изолирует пользователя от критических сбоев. Программа перехватывает:
    *   `IllegalArgumentException` — при нарушении геометрии и размеров матриц.
    *   `ArithmeticException` — при попытке деления на комплексный ноль или вычислении обратной матрицы с нулевым детерминантом.
    *   Общее исключение `Exception` — для фильтрации неверного ввода (если вместо чисел пользователь случайно вводит буквы).
*   **Управление потоком ввода:** Использование класса `java.util.Scanner` с обязательной очисткой буфера (`scanner.nextLine()`) в блоках ошибок для предотвращения бесконечных циклов консоли.
